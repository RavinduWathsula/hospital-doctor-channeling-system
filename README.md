# Smart Hospital Doctor Channeling & Appointment Management System

A professional full-stack web application designed for comprehensive hospital management.

## Architecture
- **Frontend**: React, Vite, Tailwind CSS, Framer Motion, React Router.
- **Backend**: Node.js, Express.js, JWT Authentication.
- **Database**: MySQL.

## Structure
- `/frontend`: React SPA application.
- `/backend`: Express REST API.
- `/database`: MySQL schemas and seeds.

## Setup Instructions

### Database
1. Import `database/schema.sql` into MySQL.
2. Import `database/seed.sql` to populate default data.

### Backend
1. Navigate to `/backend`.
2. Copy `.env.example` to `.env` and fill in credentials.
3. Run `npm install`.
4. Run `npm run dev`.

### Frontend
1. Navigate to `/frontend`.
2. Run `npm install`.
3. Run `npm run dev`.
